# HU40 – Consultar Líneas de una Marca

## 📌 Título

**HU40 – Consultar Líneas de Motocicleta por Marca**

---

## 🧩 Tarjeta

**Como** Administrador del Sistema  
**Necesito** consultar las líneas (modelos) de motocicletas disponibles para una marca específica  
**Para** gestionar y verificar el catálogo de referencias de motocicletas filtradas por marca

## 📋 Casos de Uso Funcionales

### Caso de Éxito

Dado que un Administrador autenticado desea consultar las líneas de motocicletas de una marca específica, cuando acceda al endpoint `GET /admin/brands/{brandId}/lines` con un ID de marca válido, entonces el sistema retornará la lista de líneas (modelos) disponibles para esa marca y mostrará el mensaje satisfactorio `MOD_MOT_BRAND_LINES_EXI_00001`.

---

### Casos de Error

#### Token No Válido o Ausente

Dado que no se proporcione un token de autenticación válido, cuando se intente acceder al endpoint, entonces el sistema retornará código HTTP 401 indicando que la autenticación es requerida.

---

#### Acceso Denegado - Rol Insuficiente

Dado que el usuario autenticado no tenga el rol ADMIN, cuando intente acceder al endpoint, entonces el sistema retornará código HTTP 401/403 indicando que no tiene permisos para acceder a este recurso.

---

#### Marca No Encontrada

Dado que el ID de marca proporcionado no exista o sea inválido, cuando el sistema intente consultar las líneas, entonces retornará una lista vacía de líneas con el mensaje de éxito correspondiente.

---

## 🔐 Seguridad

* **Autenticación:** Requerida (JWT Bearer Token)
* **Autorización:** Solo rol ADMIN
* **Middleware:** `RequireAuth` + `RequireRole(domain.RoleAdmin)`

---

| Método | Ruta | Descripción |
